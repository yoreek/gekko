Der schnellste erste Test fuer Gekko ist ein einfacher Schalter. Damit
ueberpruefst du den kompletten Ablauf: Geraet anlegen, einen GPIO waehlen,
schalten, das Dashboard sehen und verstehen, wie die Zustandsanzeige aussieht.

## Was du brauchst

- ein geflashtes Gekko-Geraet im Netz;
- irgendeinen freien GPIO, der ein echtes Signal ausgeben darf;
- im Zweifel nur ein Dummy-Board oder eine LED fuer den ersten Lauf.

## Den Schalter anlegen

1. Oeffne im Portal die **Devices**-Seite.
2. Klicke auf **Add device** und waehle **GPIO switch**.
3. Gib ihm einen Namen, waehle den GPIO und lasse die restlichen Optionen
   zunaechst auf Standard.
4. Speichere das Geraet.

## Den Schalter testen

1. Oeffne die Detailseite des neuen Schalter-Geraets.
2. Schalte ihn ein und aus.
3. Wenn du eine LED oder ein Relais angeschlossen hast, sollte sich der
   physische Ausgang sofort aendern.
4. Pinne das Geraet auf das Dashboard, damit du es spaeter sofort erreichst.

Die Konfiguration laeuft lokal auf dem Geraet weiter. Wenn du den Browser
schliesst, bleibt der Zustand erhalten.

## Was als Nächstes sinnvoll ist

Wenn der erste Schalter funktioniert, sind gute naechste Schritte:

- ein [Temperatursensor](/gekko/de/reference/devices/ds18b20/)
- ein [Thermostat](/gekko/de/reference/devices/thermostat/)
- ein [Display](/gekko/de/guides/displays/)
