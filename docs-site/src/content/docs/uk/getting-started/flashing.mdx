Готові до прошивки бінарники (`bootloader.bin`, `partitions.bin`,
`firmware.bin`, `littlefs.bin`) збираються на кожному коміті для кожного
підтримуваного чипа (класична ESP32, ESP32-S2, ESP32-S3, ESP32-C3,
ESP32-C6) та містять прошивку й файли вебпорталу.

## Вибір варіанта прошивки

| Варіант | Налаштування WiFi через BLE | GPIO 32 | Точка доступу та вебпортал | Чипи |
| --- | --- | --- | --- | --- |
| **Рекомендований** | Код BLE не компілюється у прошивку | Доступний для іншого пристрою | Доступні | ESP32, S2, S3, C3, C6 |
| **З BLE** | Увімкнено | Зарезервовано для кнопки активації BLE | Доступні | лише ESP32, S3, C3 |

Вибирайте **Рекомендований**, якщо не потрібне налаштування WiFi з мобільного
BLE-додатка: ця прошивка менша й не резервує GPIO 32. Вибирайте **З BLE**,
лише якщо потрібне налаштування через мобільний BLE-додаток; для ESP32-S2
такого варіанта немає (у чипі взагалі відсутній радіомодуль BLE), як і для
ESP32-C6 (конфлікт лінкера у фреймворку `pioarduino`/Arduino-ESP32 core 3.x)
— подробиці в `docs/esp32-board-models.md` у репозиторії.

## Варіант 1 — вебінсталятор (найпростіше)

Прошивайте напряму з браузера, без встановлення додаткового ПЗ:

<LinkButton href="/gekko/install/" icon="rocket">Відкрити вебінсталятор Gekko</LinkButton>

<Steps>

1. Під’єднайте вашу плату до комп’ютера USB **data**-кабелем.

2. Відкрийте інсталятор у **Chrome**, **Edge** або **Opera** на настільному
   комп’ютері (Web Serial недоступний у Firefox/Safari та на мобільних
   пристроях).

3. Виберіть **Рекомендований** або **З BLE**, натисніть відповідну кнопку,
   виберіть послідовний порт і підтвердьте. Інсталятор сам визначає
   під’єднаний чип — вибирати його вручну не потрібно.

4. Дочекайтеся завершення індикатора прогресу, а потім перейдіть до
   [Першого запуску та налаштування WiFi](/gekko/uk/getting-started/first-boot-wifi/).

</Steps>

:::caution
Прошивання з браузера залежить від підтримки серійного порту в ОС/USB-чипі й
має відомі проблеми на деяких комбінаціях Linux + USB-serial. Якщо не
спрацювало — скористайтеся одним із варіантів нижче: вони прошивають ті самі
бінарники.
:::

## Варіант 2 — esptool

<Tabs syncKey="os">
  <TabItem label="Windows / macOS / Linux (без Python)">

    1. Завантажте окремий бінарник `esptool` для вашої ОС зі
       [сторінки релізів esptool](https://github.com/espressif/esptool/releases).
    2. Покладіть його поруч зі скриптами в папці репозиторію `webflash/`
       (перейменуйте на `esptool` у macOS/Linux або `esptool.exe` у Windows).
    3. Запустіть `webflash/flash.sh [default|ble] [CHIP] [PORT]` (macOS/Linux)
       або `webflash/flash.bat [default|ble] [CHIP] [PORT]` (Windows), де
       `CHIP` — один з `esp32` (типово), `esp32s2`, `esp32s3`, `esp32c3`,
       `esp32c6`, той, що відповідає вашій платі. Якщо порт не вказано,
       esptool визначить його автоматично.

  </TabItem>
  <TabItem label="Python">

    ```sh
    pip install esptool
    python3 webflash/flash.py [default|ble] [CHIP] [PORT]
    ```

  </TabItem>
</Tabs>

## Варіант 3 — PlatformIO (для розробки)

Якщо збираєте з вихідного коду:

```sh
# Рекомендований (без BLE)
pio run -e esp32dev -t upload
pio run -e esp32dev -t uploadfs

# З BLE
pio run -e esp32dev_ble -t upload
pio run -e esp32dev_ble -t uploadfs

# Інші чипи: esp32s3[_ble], esp32c3[_ble], esp32s2, esp32c6
pio run -e esp32s3_ble -t upload
```

Дивіться `CLAUDE.md` у корені репозиторію та
[`docs/platformio-environments.md`](https://github.com/yoreek/gekko/blob/master/docs/platformio-environments.md) для
повного робочого процесу розробки.
