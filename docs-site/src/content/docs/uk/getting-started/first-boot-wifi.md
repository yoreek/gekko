Gekko постачається **без жорстко прошитих WiFi-облікових даних**. Під час
першого запуску пристрій піднімає власну точку доступу для налаштування, і ви
конфігуруєте мережу через портал.

## Підключення через setup access point

1. Подайте живлення на щойно прошиту плату. За кілька секунд вона підніме
   відкриту WiFi-точку доступу з назвою **`gekko-<suffix>`**, де суфікс
   береться з MAC-адреси плати — тож два контролери поруч не конфліктують.
2. Підключіться до цієї точки доступу з телефона або ноутбука. На більшості
   систем з’явиться підказка captive portal; якщо ні, відкрийте портал
   напряму по IP — `http://192.168.4.1/` (типова AP-адреса ESP32).
3. Відкрийте сторінку **WiFi** в порталі. Пристрій просканує навколишні
   мережі та покаже список.
4. Виберіть свою мережу, введіть пароль і збережіть.
5. Пристрій під’єднається до вашої мережі як станція. Setup AP керується
   state machine WiFi — він лишається доступним, поки не встановиться
   з’єднання станції, тож помилка в паролі ніколи не заблокує вас назавжди.

Після успішного підключення відкрийте портал за адресою, яку роутер видав
пристрою (дивіться список клієнтів у роутері або рядок у серійному логу
пристрою). Відтепер портал працює у вашій звичайній мережі.

## Якщо підключення не вдалося

Збережені облікові дані для недоступної мережі **не** «цеглять» пристрій:
повторні спроби станційного підключення керуються таймаутами, і setup AP
разом із порталом лишаються доступними весь час — просто перепідключіться до
AP і виправте налаштування.

## Альтернатива: BLE provisioning

Прошивка **Standard** може приймати параметри WiFi через **Bluetooth LE** за
допомогою сумісного з Espressif додатка для Android або iOS. Підключіть
нормально розімкнену кнопку між GPIO 32 і GND та утримуйте її 3 секунди, щоб
запустити BLE-режим налаштування. Його також можна запустити зі сторінки WiFi
у вебпорталі або через API. Сесія має таймаут, а збережені параметри змінюються
лише після успішного надсилання нових значень додатком.

У прошивці **Without BLE** немає коду BLE provisioning, а GPIO 32 не
резервується. Описані вище точка доступу та вебпортал доступні в обох
варіантах прошивки.
