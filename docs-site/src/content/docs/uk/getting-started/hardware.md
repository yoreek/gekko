## Контролерна плата

Gekko працює на п'яти чипах родини ESP32, для всіх є готові бінарники:
класична **ESP32**, **ESP32-S2**, **ESP32-S3**, **ESP32-C3** та **ESP32-C6**
(BLE-провіжинінг WiFi доступний лише на ESP32/S3/C3 — див. таблицю нижче).
Підійде будь-яка звичайна плата типу "DevKit" під ці чипи, і всім потрібно
**4 МБ флеш-пам'яті**. Класична ESP32 — найпростіший, найдешевший і
найпоширеніший варіант, якщо у вас ще немає конкретної плати: саме на цю
конфігурацію посилається решта документації, якщо не вказано інше:

| Розділ | Адреса у флеші |
| --- | --- |
| Bootloader | `0x1000` (класична ESP32 / ESP32-S2), `0x0` (S3 / C3 / C6) |
| Partition table | `0x8000` |
| Firmware (single app, без OTA) | `0x10000` |
| LittleFS (assets вебпорталу) | `0x370000` |

Стандартна збірка використовує схему з одним застосунком без OTA-слота, щоб
помістити прошивку, вебпортал і вашу конфігурацію пристроїв у 4 МБ. Плати з
більшим обсягом флешу теж працюють і залишають запас для опційної
[збірки з Web OTA](/gekko/uk/guides/ota-updates/).

Також потрібні **USB data-кабель** і, на деяких платах, звичайний драйвер
CP210x/CH340 для вашої операційної системи.

## Пристрої з каталогу

Усе нижче — опційне. Кожен елемент додається через вебпортал уже тоді, коли
ви його фактично під’єднуєте:

- **Реле / MOSFET-плати** на будь-якому вільному GPIO (`gpio_switch`)
- **PCF8574 / PCF8575** I2C port-експандери для додаткових виходів
- **DS18B20** водонепроникні температурні зонди на шині 1-Wire (один GPIO,
  багато датчиків)
- **NTC-терморезистори** та інші аналогові сенсори на ADC-вході, через
  **ADS1115** 16-бітний I2C ADC або **CD74HC4067** 16-канальний мультиплексор
- I2C-датчики температури та вологості **HTU21** і **AHT10**, або **DHT11** на
  одному GPIO
- OLED **SSD1306**, TFT **ST7735**, символьні **LCD1602/LCD2004** та
  чотирирозрядні модулі **TM1637**
- I2C-годинник **DS3231** або трипровідний **DS1302** — рекомендовані для
  розкладів, якщо пристрій може працювати без інтернету/NTP
- **Перистальтичні дозувальні насоси**, керовані через вихід вимикача
- **LED-драйвери / PWM-навантаження** на виводах з підтримкою LEDC
  (`analog_output`)
- Цифрові входи: поплавкові вимикачі, дверні контакти, датчики протікання
  (`binary_sensor`)

Дивіться [каталог пристроїв](/gekko/uk/reference/devices/) для повного списку
33 вбудованих типів.

:::tip
Почніть просто з самої плати. Прошите її, під’єднайте до WiFi й походіть
порталом — реальне обладнання можна додавати по одному пристрою пізніше.
:::
