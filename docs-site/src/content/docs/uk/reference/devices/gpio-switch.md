`gpio_switch` керує одним GPIO-піном як виходом on/off — релейні плати,
MOSFET-модулі, статусні світлодіоди. Зазвичай це перший пристрій, який
створюють; [інструкція з першого пристрою](/gekko/uk/getting-started/first-device/)
використовує саме його.

![GPIO switch settings](../../../../assets/screenshots/device-gpio-switch.png)

## Залежності

Немає — він безпосередньо володіє своїм GPIO-піном. (Для виходів за
PCF8574/PCF8575 експандером замість цього використовуйте
`port_expander_switch`; він має ті самі опції вимикача, що й нижче.)

## Конфігурація

| Поле | За замовчуванням | Значення |
| --- | --- | --- |
| `gpioPin` | `4` | Вихідний пін |
| `inverted` | off | Інвертувати електричний рівень — увімкніть для релейних плат з активним нулем |
| `startupState` | off | Стан виходу одразу після завантаження (якщо не відновлюється попередній) |
| `restorePreviousState` | off | Відновлювати останній стан до перезавантаження замість `startupState` |
| `safeState` | off | Стан, до якого вихід повертається, коли керуючий пристрій стає недоступним |
| `enabled` | on | Вимкнені пристрої звільняють вихід і перестають звітувати |

## Runtime та керування

Пристрій повідомляє свій живий стан on/off; перемикайте його зі списку
пристроїв, віджета switch на дашборді, REST API або Home Assistant (як
`switch`-сутність на [MQTT-збірках](/gekko/uk/guides/mqtt-home-assistant/)).

## Надає

- **switch** — ним може керувати термостат, auto switch або дозувальний насос.
- **condition** — його стан on/off може бути умовою для auto switch.
