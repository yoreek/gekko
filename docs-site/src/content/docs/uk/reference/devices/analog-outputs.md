## Навіщо потрібні димовані виходи?

Вимикач on/off достатній для нагрівача — але світло не повинно різко
стрибати з 0 до 100% о 9 ранку. Хороше акваріумне (або тераріумне, або
тепличне) світло:

- **плавно наростає і спадає** — схід і захід сонця, а не перемикач;
  риба видно як реагує на різкий перехід, а корали тим більше;
- **змінює інтенсивність протягом дня** — денний пік, м’якші ранки та вечори;
- **змішує кілька кольорових каналів** — reef-світильники зазвичай мають
  окремі royal blue, blue, white, violet і moonlight LED-стрічки, кожна зі
  своєю добовою кривою.

Gekko моделює це чотирма типами пристроїв, які стикуються як блоки. Кожен
рівень у порталі та API — це відсоток (0–100%), а з боку заліза це ESP32 PWM
(LEDC) пін, що керує входом dimming у LED driver, MOSFET-модулі або будь-
якому іншому PWM-навантаженні.

## Будівельні блоки

| Тип | Що робить |
| --- | --- |
| `analog_output` | Апаратний PWM-канал на піні |
| `fade_analog_output` | Згладжує кожну зміну в плавний перехід |
| `scheduled_analog_output` | Веде свій target уздовж добової кривої |
| `analog_output_composer` | Групує кілька каналів в один світильник |

Fade або scheduled output бере рівно одну залежність з роллю `analog_output`
і *сам надає ту саму роль*, тож вони складаються:

![Decorator chain: scheduled output computes the level, fade smooths it, analog output writes PWM](../../../../../assets/diagrams/analog-chain.svg)

- **Fade** — `maxStep` (відсотків за крок) і `stepIntervalMs` задають
  швидкість переходу; типове ≈1% кожні 200 ms перетворює будь-яку зміну,
  включно з ручним рухом слайдера, на м’який перехід.
- **Scheduled** — до 10 точок `(time, level)` на добу, інтерпольованих між
  точками. Режими: **Off**, **Manual** (фіксований рівень), **Scheduled**
  (слідувати кривій). Без придатного годинника вихід сходить у нуль, а не
  тримає застарілий рівень.

Реєстр гарантує, що на кожному виході є **не більше одного контролера** — ви
не зможете випадково під’єднати два schedule до одного каналу.

## Робочий приклад: п’ятиканальне акваріумне світло

Мета — день, що виглядає ось так:

![Daily curves of five channels: blues ramp first and linger, white peaks midday, violet accents, moonlight at night](../../../../../assets/diagrams/aquarium-light-day.svg)

Сині канали піднімаються першими і спадають останніми (корали фотосинтезують
переважно в синьому), теплий white заповнює полуденні години, violet додає
флуоресцентний акцент, а слабкий moonlight сяє вночі. Щоб зібрати це:

1. Створіть п’ять пристроїв **`analog_output`**, по одному на кожен LED driver
   пін: "Royal blue LEDC", "Blue LEDC", "White LEDC", "Violet LEDC",
   "Moonlight LEDC".
2. Обгорніть кожен у **`fade_analog_output`** ("Royal blue fade" → target =
   "Royal blue LEDC", …), щоб зміни не були ривками.
3. Обгорніть кожен fade у **`scheduled_analog_output`** ("Royal blue schedule"
   → target = "Royal blue fade", …) і намалюйте добову криву для кожного каналу.
4. Створіть один **`analog_output_composer`** "Aquarium light" і додайте
   п’ять scheduled output як його канали.

![Aquarium light composer in the portal](../../../../../assets/screenshots/device-analog-composer.png)

Тепер composer поводиться як *саме* це світло:

- **Один режим для всього світильника** — перемикання composer між Off /
  Manual / Scheduled штовхає цей режим на всі канали й тримає їх синхронними,
  якщо якийсь з них колись роз’їдеться. Off обнуляє все.
- **Один редактор** — усі криві каналів на одному графіку, редагуються
  прямо шляхом перетягування точок (правий клік додає/видаляє, опційне
  прив’язування 15 хв/5%, підкладка sunrise/sunset для орієнтиру); у режимі
  manual показується один слайдер на канал.
- **Одна картка дашборду** — закріпіть composer для компактного
  багатоканального preview розкладу.

Composer потрібен лише тоді, коли кілька каналів мають діяти як один
світильник — одно-канальне світло це просто кроки 1–3 з однією цепочкою.
Fade-шар можна пропустити, якщо вас не хвилюють плавні переходи.

Повний посібник із підключенням, налаштуванням і перевіркою — у проєкті
[«Багатоканальний світильник»](/gekko/uk/projects/multichannel-light/).

## Runtime та керування

Усі чотири типи повідомляють свій живий рівень (fade ще й target та те, чи
він усе ще в переході). Слайдер дашборду або команда `setOutput` керує
каналом напряму; зміни режиму йдуть через `setMode`. На
[MQTT builds](/gekko/uk/guides/mqtt-home-assistant/) канали виявляються в Home
Assistant. Внутрішні деталі:
[`docs/analog-output.md`](https://github.com/yoreek/gekko/blob/master/docs/analog-output.md).
