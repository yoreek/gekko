## Прошивання

### Вебінсталятор каже, що мій браузер не підтримується

Web Serial існує лише в Chromium-браузерах — використовуйте **Chrome, Edge
або Opera на десктопі**. Firefox, Safari та всі мобільні браузери не
вміють прошивати. Або використайте [esptool scripts](/gekko/getting-started/flashing/),
які працюють всюди.

### Інсталятор не показує serial port моєї плати

- Використовуйте USB **data**-кабель — багато комплектних кабелів є лише
  зарядними.
- Встановіть драйвер CP210x або CH340, який потрібен USB-serial чипу на вашій
  платі.
- На Linux додайте себе в serial group (`sudo usermod -a -G dialout $USER`,
  потім перелогіньтесь) і пам’ятайте, що деякі комбінації Linux + Chrome +
  USB-chip можуть бути проблемними через Web Serial — шлях через esptool
  лишається надійним fallback.
- Закрийте все інше, що тримає порт (serial monitors, IDEs).

## Перший запуск і WiFi

### Точка доступу setup `gekko-…` так і не з’являється

- Дайте платі ~10 секунд після подачі живлення.
- Якщо пристрій уже прошивали раніше й у нього лишилися старі облікові дані,
  він одразу перейде в station mode — тоді шукайте його IP у списку клієнтів
  вашого роутера.
- Перепрошийте з опцією стирання (вебінсталятор пропонує "erase device"; з
  esptool спершу `esptool erase_flash`) — так ви повернете чистий перший запуск.

### Я під’єднався до setup AP, але портал не відкривається

Не кожна ОС автоматично показує captive portal. Відкрийте
`http://192.168.4.1/` у браузері самі.

### Я зберіг неправильні WiFi-облікові дані

Нічого не втрачено: повторні спроби підключення керуються timeout-ами, а
setup AP лишається доступною паралельно з ними. Під’єднайтеся знову до
`gekko-…` AP і виправте налаштування на WiFi-сторінці.

## Портал і пристрої

### Портал завантажується, але пристрій показує `dependency_blocked`

Одна з його залежностей вимкнена, видалена або faulted — наприклад, DS18B20,
чия 1-Wire bus-пристрій вимкнена. Спершу виправте батьківський пристрій;
дочірній відновиться сам.

### Мій DS18B20 не з’являється у скані шини

Перевірте pull-up ~4.7 kΩ між data і 3.3 V та саму проводку. Здоровий зонд
сканується з family code `28` і 16-символьою адресою без CRC flag.

### Розклади ніколи нічого не вмикають

Для розкладів потрібен правдоподібний годинник. Задайте часовий пояс і NTP на
сторінці **Time**, або додайте DS3231 RTC. І не забувайте, що auto switch має
бути в режимі **Auto** — ручний override Off/On ігнорує умови, а auto switch
без прикріплених умов за замовчуванням лишається вимкненим.

### Куди поділася сторінка OTA / MQTT?

Ці сторінки з’являються лише в збірках прошивки, скомпільованих із
відповідною функцією — див. [OTA updates](/gekko/guides/ota-updates/) і
[MQTT & Home Assistant](/gekko/guides/mqtt-home-assistant/).

## Відновлення

### Factory reset

Перепрошийте з повним стиранням (опція erase у вебінсталяторі або
`esptool erase_flash` + reflash). Це очищає WiFi-облікові дані та весь
реєстр пристроїв — спочатку експортуйте [backup](/gekko/guides/backup-restore/),
якщо хочете потім відновити налаштування.

### Яку версію прошивки я зараз використовую?

`GET /api/system/version`, сторінка System у порталі або рядок
`Gekko booting version=…` у серійному boot log.
