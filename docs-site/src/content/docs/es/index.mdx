import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid stagger>
  <Card title="Sin reflashear para cada proyecto" icon="setting">
    Añade interruptores, sensores, pantallas, horarios y bombas desde el portal
    web mientras el sistema está funcionando. El registro de dispositivos, el
    grafo de dependencias y el diseño del panel permanecen en el dispositivo,
    nunca en un archivo YAML que tengas que recompilar.
  </Card>
  <Card title="Local-first" icon="laptop">
    El portal se sirve por WiFi desde la memoria flash del propio ESP32. MQTT,
    el descubrimiento de Home Assistant y las actualizaciones OTA son
    opcionales y están desactivados por defecto.
  </Card>
  <Card title="Registro tipado de dispositivos" icon="puzzle">
    Los dispositivos declaran dependencias entre sí — un interruptor detrás de
    un expansor de puertos, un sensor detrás de un bus I2C o una bomba controlada
    por un horario — y el registro valida y conserva ese grafo.
  </Card>
  <Card title="Pantallas, horarios y dosificación" icon="rocket">
    Pantallas OLED/TFT con diseñador visual de layouts, horarios con precisión
    de minuto, automatización basada en condiciones, termostatos y bombas
    dosificadoras con calibración e historial.
  </Card>
  <Card title="Home Assistant con un interruptor" icon="heart">
    Activa un interruptor en la página del dispositivo y aparecerá en Home
    Assistant como una entidad nativa — controlable desde HA y funcionando
    todavía de forma local.
  </Card>
  <Card title="Copia de seguridad y restauración" icon="document">
    Exporta toda la configuración como un único paquete legible y editable, y
    restáurala en cualquier controlador Gekko.
  </Card>
  <Card title="Habla tu idioma" icon="translate">
    El portal está disponible en inglés, ucraniano, ruso, alemán, español,
    francés e italiano, con detección automática del idioma del navegador.
  </Card>
</CardGrid>
