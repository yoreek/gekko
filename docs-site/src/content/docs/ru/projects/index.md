Эти руководства начинаются с практического результата, а не с технического
типа устройства. В каждом указаны оборудование, граф устройств Gekko, порядок
создания и безопасная проверка результата.

| Проект | Что получится | Основные понятия |
| --- | --- | --- |
| [Монитор температуры](/gekko/ru/projects/temperature-monitor/) | Текущее значение и история температуры с DS18B20 | 1-Wire, сканирование, ROM-адрес, проверка показаний |
| [Термостат с реле](/gekko/ru/projects/thermostat-with-relay/) | Управление нагревателем или охладителем по DS18B20 | 1-Wire, датчик, выключатель, две зависимости, безопасное состояние |
| [Реле по расписанию](/gekko/ru/projects/scheduled-relay/) | Реле по времени и дням недели | часы, расписание, Auto Switch, безопасный выход |

Позднее здесь появятся дисплей с показаниями датчиков, дозирующий насос и
многоканальный аквариумный свет.

Если технический тип уже известен, откройте
[каталог устройств](/gekko/ru/reference/devices/). Если нет — сначала выберите
проект, а затем переходите по его ссылкам только к нужным справочным страницам.
