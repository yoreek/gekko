## Плата контроллера

Gekko работает на пяти чипах семейства ESP32, для всех есть готовые
скомпилированные бинарники: классическая **ESP32**, **ESP32-S2**,
**ESP32-S3**, **ESP32-C3** и **ESP32-C6** (BLE-провижининг WiFi доступен
только на ESP32/S3/C3 — см. таблицу ниже). Подойдёт любая обычная плата в
стиле "DevKit" под эти чипы, и всем нужно **4 МБ флеш-памяти**. Классическая
ESP32 — самый простой, дешёвый и распространённый вариант, если у вас ещё
нет конкретной платы: именно на эту конфигурацию ссылается остальная
документация, если не указано иное:

| Раздел | Смещение во флеше |
| --- | --- |
| Загрузчик | `0x1000` (классическая ESP32 / ESP32-S2), `0x0` (S3 / C3 / C6) |
| Таблица разделов | `0x8000` |
| Прошивка (один app, без OTA) | `0x10000` |
| LittleFS (ресурсы веб-портала) | `0x370000` |

По умолчанию используется схема с одним приложением без OTA-раздела, чтобы
поместить прошивку, веб-портал и конфигурацию устройства в 4 МБ. Платы с
большим объёмом флеша тоже подходят и оставляют запас под опциональную
[Web OTA build](/gekko/ru/guides/ota-updates/).

Вам также понадобится **USB-кабель для передачи данных** и, на некоторых
платах, обычный драйвер CP210x/CH340 для USB-UART под вашу операционную
систему.

## Внешние устройства из каталога

Всё перечисленное ниже необязательно — вы добавляете каждый компонент из
веб-портала только тогда, когда реально подключаете его:

- **Реле / MOSFET-платы** на любом свободном GPIO (`gpio_switch`)
- **I2C-расширители портов PCF8574 / PCF8575** для дополнительных выходов
  выключателей
- **DS18B20** водонепроницаемые температурные щупы на шине 1-Wire (один GPIO,
  много датчиков)
- **NTC-термисторы** и другие аналоговые датчики на пине АЦП, через
  **ADS1115** 16-битный I2C АЦП или **CD74HC4067** 16-канальный
  мультиплексор
- I2C-датчики температуры и влажности **HTU21** и **AHT10**, либо **DHT11** на
  одном GPIO
- OLED **SSD1306**, TFT **ST7735**, символьные **LCD1602/LCD2004** и
  четырёхразрядные модули **TM1637**
- I2C-часы **DS3231** или трёхпроводные **DS1302** — рекомендуются для
  расписаний, если устройство может работать без интернета/NTP
- **Перистальтические дозирующие насосы**, управляемые через выход выключателя
- **Драйверы светодиодов / PWM-нагрузки** на пинах, поддерживающих LEDC
  (`analog_output`)
- Цифровые входы: поплавковые выключатели, дверные контакты, датчики
  протечки (`binary_sensor`)

См. [device catalog](/gekko/ru/reference/devices/) для полного списка всех 33
встроенных типов устройств.

:::tip
Начните только с самой платы. Прошейте её, подключите к WiFi и изучите
портал — реальное оборудование можно добавлять по одному устройству позже.
После подключения выберите точную модель вашей платы на странице настроек
**Controller board** («Плата контроллера») *до того*, как добавите любое
устройство, использующее пины, — доступность GPIO (ADC, strapping, только для
входа, зарезервированные пины) отличается для каждой платы, и выбор пина в
настройках любого устройства опирается именно на это значение.
:::
