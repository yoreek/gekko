Gekko поставляется **без жёстко прошитых WiFi-учётных данных**. При первом
запуске устройство поднимает собственную точку доступа для настройки, а вы
конфигурируете сеть через портал.

## Подключение через точку доступа для настройки

1. Подайте питание на только что прошитую плату. Через несколько секунд она
   поднимет открытую WiFi-точку доступа с именем **`gekko-<suffix>`**, где
   суффикс берётся из MAC-адреса платы — так два контроллера рядом никогда не
   конфликтуют.
2. Подключитесь к этой точке доступа с телефона или ноутбука. На большинстве
   систем появится запрос captive portal; если этого не произошло, откройте
   портал вручную по IP — `http://192.168.4.1/` (адрес ESP32 AP по умолчанию).
3. Откройте страницу **WiFi** в портале. Устройство просканирует ближайшие
   сети и покажет список.
4. Выберите свою сеть, введите пароль и сохраните настройки.
5. Устройство подключится к вашей сети как станция. Точка доступа для
   настройки управляется WiFi state machine — она остаётся доступной до тех
   пор, пока не будет установлено соединение в режиме станции, так что опечатка
   в пароле никогда не блокирует доступ к устройству.

После успешного подключения откройте портал по адресу, который роутер выдал
устройству (посмотрите список клиентов роутера или строку в serial log
устройства). С этого момента портал обслуживается в вашей обычной сети.

## Если подключение не удалось

Сохранённые учётные данные для недоступной сети **не превращают устройство в
кирпич**: попытки подключения в режиме станции идут по таймауту, а точка
доступа для настройки вместе с порталом всё время остаются доступными — можно
снова подключиться к AP и исправить настройки.

## Альтернатива: BLE provisioning

Прошивка **Standard** может получать параметры WiFi по **Bluetooth LE** через
совместимое с Espressif приложение для Android или iOS. Подключите нормально
разомкнутую кнопку между GPIO 32 и GND и удерживайте её 3 секунды, чтобы
запустить BLE-режим настройки. Его также можно запустить со страницы WiFi в
веб-портале или через API. Сессия ограничена по времени, а сохранённые
параметры меняются только после успешной передачи новых значений приложением.

В прошивке **Without BLE** код BLE provisioning отсутствует, а GPIO 32 не
резервируется. Описанные выше точка доступа и веб-портал доступны в обоих
вариантах прошивки.
