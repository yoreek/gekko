  </Card>
  <Card title="Типизированный реестр устройств" icon="puzzle">

    проверяет и сохраняет этот граф.
  </Card>
  <Card title="Дисплеи, расписания, дозирование" icon="rocket">

    расписания с точностью до минуты, автоматика по условиям, термостаты и
    дозирующие насосы с калибровкой и историей.
  </Card>
  <Card title="Home Assistant одним переключателем" icon="heart">
    Включите переключатель на странице устройства — и оно появится в Home

    локально.
  </Card>
  <Card title="Резервное копирование и восстановление" icon="document">

    редактирования человеком, и восстановите её на любом контроллере Gekko.
  </Card>
  <Card title="Говорит на вашем языке" icon="translate">

    браузера.
