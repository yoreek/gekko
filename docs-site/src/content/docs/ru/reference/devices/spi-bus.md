## Что такое SPI?

SPI (Serial Peripheral Interface) — это быстрая последовательная шина: если
[I2C](/gekko/ru/reference/devices/i2c-bus/) упирается в 400 kHz, SPI спокойно
тактует десятки MHz, поэтому на нём и живут цветные дисплеи. Цена за скорость —
больше проводов: общие линии **clock** (SCK) и **data** (MOSI, а при
необходимости MISO для данных обратно), плюс отдельный **chip-select** (CS)
на каждое устройство — именно так устройства различаются вместо адресов.

В Gekko шина — это устройство `spi_bus`: оно владеет общими пинами SCK/MOSI/MISO
и SPI-host ESP32. Сейчас его единственный потребитель — цветной TFT-дисплей
**ST7735**; его собственные пины CS/DC/reset принадлежат уже устройству
дисплея, а не шине.

## Проводка

![Проводка SPI: общие SCK и MOSI для ST7735, chip-select и data/command-пины для каждого дисплея](../../../../../assets/diagrams/spi-wiring.svg)

Типичный модуль ST7735 подключается так (обозначения на шелкографии могут
отличаться):

| Пин модуля | Пин ESP32 (по умолчанию) | Принадлежит |
| --- | --- | --- |
| SCK / CLK | GPIO 18 | `spi_bus` |
| SDA / MOSI / DIN | GPIO 23 | `spi_bus` |
| CS | GPIO 5 | устройство `st7735` |
| DC / A0 | GPIO 2 | устройство `st7735` |
| RES / RST | — (или любой свободный GPIO) | устройство `st7735` |
| VCC, GND, LED/BLK | 3.3 V / GND | питание |

Дисплеи никогда не отправляют данные обратно, поэтому **MISO остаётся на −1**
(не используется). Второе SPI-устройство просто разделит SCK/MOSI и получит
свой CS-пин.

## Устройство шины и диагностика

Как и другие шины, `spi_bus` показывает live diagnostics — счётчики ошибок и
состояние транзакций — а его отключение блокирует дисплей статусом
`dependency_blocked` вместо того, чтобы оставлять старые пиксели на экране.

## Конфигурация

| Поле | По умолчанию | Значение |
| --- | --- | --- |
| `host` | `VSPI` | Какой аппаратный SPI-контроллер ESP32 использовать |
| `sckPin` | `18` | Общий clock |
| `mosiPin` | `23` | Общий data out |
| `misoPin` | `-1` | Data in — не используется для дисплеев, задаётся только если будущему устройству нужен readback |
| `enabled` | on | Отключение шины блокирует все устройства на ней |
