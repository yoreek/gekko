`gpio_switch` управляет одним GPIO как выходом on/off — платы реле, модули
MOSFET, статусные светодиоды. Обычно это первое устройство, которое вы
создаёте; [пошаговое руководство по первому устройству](/gekko/ru/getting-started/first-device/)
использует именно его.

![Настройки GPIO switch](../../../../../assets/screenshots/device-gpio-switch.png)

## Зависимости

Нет — он напрямую владеет своим GPIO. (Для выходов за PCF8574/PCF8575
expander используйте `port_expander_switch`; у него те же варианты настроек,
что и ниже.)

## Конфигурация

| Поле | По умолчанию | Значение |
| --- | --- | --- |
| `gpioPin` | `4` | Выходной пин |
| `inverted` | off | Инвертировать электрический уровень — включайте для активных по низкому уровню плат реле |
| `startupState` | off | Состояние выхода сразу после загрузки (если не восстанавливать прошлое) |
| `restorePreviousState` | off | Восстановить последнее состояние до перезагрузки вместо `startupState` |
| `safeState` | off | Состояние, в которое выход уходит, если управляющее устройство становится недоступным |
| `enabled` | on | Отключённые устройства освобождают выход и перестают сообщать состояние |

## Runtime и управление

Устройство сообщает своё текущее состояние on/off; переключать его можно из
списка устройств, виджета switch на дашборде, REST API или Home Assistant
(как сущность `switch` на [MQTT builds](/gekko/ru/guides/mqtt-home-assistant/)).

## Предоставляет

- **switch** — может управляться термостатом, auto switch или дозирующим насосом.
- **condition** — его состояние on/off может быть условием для auto switch.
